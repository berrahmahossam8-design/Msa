بناء APK للطالب المسلم (مع الأذان في الخلفية) من الجوال فقط
===========================================================
1) فكّ ضغط هذا الملف (من تطبيق الملفات: اضغط مطوّلًا ← استخراج).
2) أنشئ حسابًا مجانيًا في github.com ثم: New repository ← اسمه almuslim ← Create.
3) في صفحة المستودع: "uploading an existing file" ← اختر كل الملفات التي استخرجتها
   (index.html و package.json و capacitor.config.json و apply.py وملفات .java الأربعة،
    وملف adhan.mp3 إن وضعته) ← Commit changes.
   * اختياري: ضع ملف صوت الأذان باسم adhan.mp3 مع الملفات، وإلا يُحمَّل من الإنترنت.
4) أنشئ ملف البناء: Add file ← Create new file، في خانة الاسم اكتب بالضبط:
      .github/workflows/build.yml
   والصق داخله محتوى الملف build.yml من هذه الحزمة ← Commit.
5) افتح تبويب Actions وانتظر 5-10 دقائق حتى تظهر علامة ✓ خضراء.
6) افتح تلك العملية ← في الأسفل Artifacts ← نزّل «الطالب-المسلم-APK» (ملف ZIP) ← فكّه ← ثبّت app-debug.apk
   (اسمح بتثبيت التطبيقات من مصدر غير معروف).
7) افتح التطبيق ← «تفعيل الأذان» ← اسمح بالإشعارات و«المنبّهات والتذكيرات» ← اختر «عدم التحسين» للبطارية.
   في شاومي/سامسونج/أوبو فعّل أيضًا «التشغيل التلقائي».
8) إذا فشل البناء (علامة ✗ حمراء): افتح العملية وانسخ آخر 30 سطرًا من الخطأ وأرسلها لي.
لتحديث التطبيق لاحقًا: استبدل index.html في المستودع (Edit/Upload) فيُبنى APK جديد تلقائيًا.
